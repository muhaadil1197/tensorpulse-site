# Tensorpulse Privacy Policy

_Last updated: November 2026_

Tensorpulse is a private tool used only by the owner of the Tensorpulse YouTube channel to upload videos to that channel.

**What data the app accesses:** The app uses the YouTube Data API only to upload videos, set thumbnails and manage metadata on the owner's own YouTube channel.

**What we store:** OAuth credentials are stored only as encrypted secrets in the owner's private GitHub repository. No viewer or third-party user data is collected, stored, sold or shared.

**Google API Services:** Tensorpulse's use of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

**Revoking access:** Access can be revoked at any time at https://myaccount.google.com/permissions

**Contact:** Use the contact options on https://www.youtube.com/@Tensorpulse
